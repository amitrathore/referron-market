# Changelog

## 0.1.2 — 2026-11-23

- Turn on Shoptype in preview so operators can connect and manage Referron from
  app.shoptype.com; purchasing and live payments stay off.
- Deploy forwards `SHOPTYPE_SERVICE_TOKEN` and refuses a live Stripe key while in preview.

## 0.1.1 — 2026-11-04

- Add Insights using the Attention Protocol, with permanent redirects from essay URLs.
- Introduce a browse-only Yvatar Store with nine real credit products and reviewed catalog refresh tooling.

## 0.1.0 — 2026-11-02

- Add Referron-branded marketplace with catalog, storefronts, cart, orders,
  referral sharing, earnings, and seller/operator workflows.
- Reuse existing Intergraph runtime and economic protocols; start with an empty catalog.
- Add isolated local Compose stack, Fly deployment configuration, CI, and operating docs.
